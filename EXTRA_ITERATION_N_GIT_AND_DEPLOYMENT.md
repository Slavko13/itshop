# Дополнительная итерация N — Git и автоматическая выкладка

## Цель

Перевести результат проекта в безопасный исходный репозиторий и обеспечить повторяемую сборку и обновление существующего WordPress на сервере одной командой.

## Реализовано

- Git отслеживает только проектные исходники, документацию, локальную Docker-среду и тесты.
- WordPress Core, сторонние плагины, uploads, дампы, логи, серверные метаданные и секреты исключены.
- Добавлен versioned release archive с manifest и commit hash.
- Добавлены локальные проверки Docker, PHP lint и HTTP smoke.
- Добавлена доставка по SSH/SCP без хранения пароля в репозитории.
- Перед заменой кода сервер сохраняет backup темы и плагина.
- Добавлен откат по `Release id`.
- База данных и рабочие данные не изменяются автоматическим code deployment.

## Команда релиза

```powershell
.\deploy.ps1 -Target production
```

## Ограничение текущей среды

Фактическая отправка в удалённый Git и на production требует URL Git-репозитория, SSH-хоста, пользователя, пути WordPress и локального SSH-ключа владельца. Эти значения не хранятся в исходниках.
