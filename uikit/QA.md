# Проверка UI KIT v3 — история проверки

## Результат

136 / 136 автоматических проверок прошли: 49 визуальных и геометрических, 71 взаимодействия, 16 реестра и расширенных компонентов. Runtime exceptions в лаборатории не обнаружены.

## Что проверено

- Шрифты, 10 типографических стилей, 20 разделов, геометрия пяти вариантов кнопок и focus, центровка поиска и полей, контроль горизонтального переполнения.
- Контраст проверяемых текстовых пар ≥ 4.5:1, focus ≥ 3:1; disabled исключён из контрастного набора.
- 43 уникальных контракта, зависимости и ссылки на токены, 56 соответствующих SVG.
- Table header 48 px, стандартные rows 72 px, общие колонки, центровка selection и сумм, геометрия skeleton.
- Avatar min hit area, семь состояний quantity, фактический счётчик textarea.
- Ввод до blur, ошибки после blur/submit, error summary и focus, read only / disabled, Unicode counter, серверные ошибки без потери данных.
- Защита от повторных отправок и устаревших ответов, payload snapshot, ручное подтверждение combobox и keyboard.
- Сортировка, выбор строк / indeterminate, диапазоны денежных значений и дат, draft/apply/reset.
- Modal: initial focus, Tab / Shift+Tab, Escape, возврат focus, pending и повтор после ошибки.
- Coupon pending/applied/remove/rejection; masked key, копирование исходного значения, Clipboard error fallback без неожиданного раскрытия.
- Responsive 375 / 768 / 1440 px, доступность только одной презентации таблицы, отсутствие горизонтального переполнения документа.
- Визуальный просмотр новых разделов; сообщения и подписи исправлены по результатам просмотра.

## Проверка Paper

Тестово импортированы header таблицы и три строки, error-dialog и revealed license field. Проверены интервалы, типографика, контраст, совпадение вертикальных колонок, целые края и fit. Computed styles подтвердили table width 1280 px, header height 48 px, dialog width 520 px и license width 560 px. Manrope и Menlo доступны. Временный тестовый artboard завершён и удалён.

Ранее в v2 отдельно проверены кнопки, search и copy-tooltip. Полный импорт всех 20 разделов за один раз не проверялся.

## Объём проверки

Browser checks выполнены в desktop Chrome через Playwright. Тесты используют локальные имитации ответов и подменённый Clipboard; реальные аккаунты, оплаты и выдача лицензий не подключены. Safari, Firefox и ручная проверка screen reader не выполнялись. Это спецификация и лаборатория отдельных компонентов, не готовая production-библиотека.
