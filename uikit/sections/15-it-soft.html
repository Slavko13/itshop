Combobox
Arrow Up / Down меняют активный вариант; Enter подтверждает; Escape закрывает popup без нового выбора.
Поиск
Debounce 300 ms. Устаревший ответ не заменяет результаты более нового запроса.
Фильтры
Пока пользователь меняет draft, результаты остаются прежними. «Показать» применяет значения.
Сброс
Возвращает значения по умолчанию, применяет их и переводит список на первую страницу.
Даты
Пустая граница = без ограничения. Дата начала должна быть не позже даты окончания.
