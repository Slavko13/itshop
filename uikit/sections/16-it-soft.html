Ключ
Доступность приходит от API. Показать и скопировать — разные действия; сообщение об успехе только после успешного копирования.
Купон
Одна проверка за раз. Ошибка не очищает введённый код. Применённая скидка и сумма — из ответа сервера.
Оплата
Статус подтверждается сервером. Возврат со страницы оплаты запускает проверку, а не сразу показывает «Оплачено».
Количество
Границы приходят из данных товара. Не показывать окончательную сумму, пока пересчёт не подтверждён.
