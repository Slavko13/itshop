IT СОФТ — UI KIT v3
19 визуальных разделов · 43 контракта компонентов · 56 SVG-иконок

НАЧАТЬ ЗДЕСЬ
1. it-soft-ui-kit.html — открыть в браузере: вид компонентов и состояния.
2. it-soft-interactions.html — открыть рядом: проверяемые взаимодействия отдельных компонентов.
3. handoff.md — размеры, токены, сборка и источники.
4. behavior.md — ввод, blur/submit, ошибки, async, таблицы, keyboard, mobile и границы API.
5. component-index.md / components.json — список компонентов, props, states, events, dependencies.

ДЛЯ PAPER
В просмотре нажмите «Скопировать HTML для Paper» и вставьте на canvas.
Можно скопировать весь текст it-soft-paper.html. Файлы sections/*.html позволяют переносить разделы отдельно.
Manrope 400/500/600/700 должен быть доступен; Menlo используется для лицензионного кода.
Paper HTML содержит inline flex-фреймы и SVG. Это визуальная спецификация.

ДЛЯ РАЗРАБОТКИ
it-soft-tokens.json — канонические значения.
it-soft-reference.css — CSS-ориентир, адаптировать под стек проекта.
it-soft-interactions.js — читаемый код лаборатории (в HTML он уже встроен).
Данные, ответы, купон SOFT10 и ключ из X в лаборатории демонстрационные.
Серверные ограничения, оплаты, авторизация и выдача ключей подключаются через API проекта.

ПРОВЕРКА
QA.md — проверенный объём и ограничения проверки.
qa-report.json — результаты сценариев и хэши файлов.
it-soft-kit-assets/ — отдельные SVG и лицензии.
Полные макеты страниц и растровые вырезки скриншотов в комплект не входят.
