# Повторный Lighthouse-аудит IT Софт, Keysoft и Rusoft

Дата проверки: 26 октября 2026 года
Проверяемые сайты: `https://test.itsoft.store`, `https://keysoft.store`, `https://rusoft.shop`
Инструмент: Lighthouse 13.5.0, Navigation audit, `throttling-method=simulate`

Для каждого сайта проверены главная, категория Microsoft Office и карточка товара. Каждая страница измерена в профилях Mobile и Desktop по два раза. В итоговых таблицах используется медиана двух запусков. Всего выполнено 36 свежих Lighthouse-аудитов.

## Функциональные проверки IT Софт

- Карточка товара и корзина прошли проверки на ширинах 320–1440 px.
- Состояние «В корзине» отображается корректно.
- Повторный клик открывает `/cart/` и больше не увеличивает количество товара.
- Недоступные товары отсутствуют в рекомендациях и поиске.
- Мобильный каталог, меню, статьи, формы входа и cookie-баннер прошли проверку.
- Единая система интерфейса: 70 из 70 межстраничных проверок пройдены.
- Каталог, поиск, главная и checkout прошли все проверки, кроме одной проверки хлебных крошек.

## Найденный дефект

На второй странице категории хлебные крошки не содержат отдельного элемента с номером страницы. Вместо ожидаемого `Главная / Microsoft Windows / Windows 11 / Страница 2` отображается `Главная / Microsoft Windows / Windows 11`.

## Следующие приоритеты

1. Уменьшить мобильный LCP карточки товара с 6,4 секунды.
2. Ускорить мобильную категорию и главную.
3. Оптимизировать адаптивные изображения и заголовки кеширования.
4. Исправить точечные замечания контраста и размеров интерактивных целей.
5. Добавить номер страницы в хлебные крошки пагинированной категории.
