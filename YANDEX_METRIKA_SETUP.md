# Яндекс Метрика для IT Софт

Интеграция установлена как обязательный модуль WordPress и не требует активации плагина. Пока ID счётчика не заполнен, сайт не загружает код Яндекса и ничего не отправляет.

## 1. Создать два счётчика

Создайте отдельные счётчики:

- `IT Софт — production`: `https://itsoft.store`;
- `IT Софт — test`: `https://test.itsoft.store`.

В обоих счётчиках включите:

- Вебвизор;
- карту кликов;
- карту ссылок;
- аналитику форм;
- электронную коммерцию, контейнер `dataLayer`.

Не объединяйте тестовый и боевой сайты в одном счётчике: тестовые заказы не должны искажать выручку и конверсию production.

## 2. Подключить счётчики к сайту

В WordPress откройте `Настройки → IT Софт — Метрика` и вставьте ID обоих счётчиков. Проверьте списки боевых и тестовых доменов, оставьте включённым запуск только после согласия на cookies и сохраните настройки.

Для короткой диагностики можно включить журнал событий. В консоли браузера сообщения будут начинаться с `[ITSoft Metrika]`. После проверки журнал лучше выключить.

## 3. Создать JavaScript-цели

В каждом счётчике создайте цели типа «JavaScript-событие». Идентификатор нужно копировать без изменений:

| Идентификатор | Назначение |
| --- | --- |
| `ym-product-view` | просмотр карточки товара |
| `ym-add-to-cart` | успешное добавление товара в корзину |
| `ym-begin-checkout` | начало оформления заказа |
| `ym-add-payment-info` | выбор способа оплаты |
| `ym-purchase` | успешная оплаченная покупка |
| `ym-register` | успешная регистрация |
| `ym-login` | успешная авторизация покупателя |
| `ym-site-search` | использование поиска |
| `itsoft-distribution-download` | скачивание дистрибутива |
| `itsoft-license-copy` | успешное копирование лицензионного ключа |
| `itsoft-review-submit` | успешная отправка отзыва |
| `itsoft-checkout-error` | ошибка оформления заказа |

Дополнительно создайте встроенную цель Метрики «Поиск по сайту». Параметр поискового запроса WordPress — `s`.

## 4. Собрать составные цели

Основная воронка продаж:

1. `ym-product-view`;
2. `ym-add-to-cart`;
3. `ym-begin-checkout`;
4. `ym-add-payment-info`;
5. `ym-purchase`.

Воронка аккаунта:

1. `ym-register`;
2. `ym-login`;
3. `ym-purchase`.

## 5. Настроить отчёты и дашборд

Добавьте виджеты за 7 и 30 дней:

- посетители, визиты и доля новых посетителей;
- источники трафика и UTM-кампании;
- устройства и мобильная конверсия;
- просмотры товаров → корзина → оформление → оплата;
- количество заказов, выручка и средний чек из отчёта электронной коммерции;
- популярные товары и товары с большим числом просмотров без покупки;
- поисковые запросы, поиск без результатов и конверсия после поиска;
- скачивания дистрибутивов, копирования ключей и отправленные отзывы;
- ошибки оформления заказа.

Для рабочих отчётов исключайте сегмент `itsoft_user_type = staff`. Значение передаётся без имени, e-mail, телефона, лицензионного ключа и других персональных данных.

## 6. Приёмочная проверка на тестовом сайте

1. Откройте сайт в режиме инкогнито: до принятия cookies запросов к `mc.yandex.ru` быть не должно.
2. Примите cookies и проверьте визит в режиме реального времени тестового счётчика.
3. Откройте карточку товара, добавьте товар в корзину, перейдите к оформлению, выберите тестовую оплату и завершите заказ.
4. Проверьте достижение пяти шагов основной воронки и появление заказа в электронной коммерции.
5. Проверьте поиск, скачивание дистрибутива, копирование ключа и отправку отзыва.
6. Обновите страницу успешного заказа: покупка не должна задвоиться в этом браузере.
7. Убедитесь, что события тестового заказа отсутствуют в production-счётчике.

После приёмки повторите короткий контрольный заказ на production только разрешённым способом оплаты.
