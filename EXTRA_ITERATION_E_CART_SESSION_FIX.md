# Extra-итерация E — единая сессия добавления товара и корзины

Статус: реализовано, автоматическая проверка пройдена, ожидает короткой ручной приёмки.

## Симптом

На карточке товара кнопка визуально срабатывала, но после перехода на `/cart/` пользователь видел сообщение «Ваша корзина пока пуста», а счётчик в шапке оставался нулевым.

## Причина

Первое добавление выполнялось напрямую через WooCommerce Store API. В новой гостевой сессии API-корзина принимала товар (`201 Created`), но обычная PHP-страница корзины не получала стандартную cookie-сессию WooCommerce. В результате карточка товара и `/cart/` читали разные состояния корзины.

## Исправлено

- первое добавление выполняется через штатный WooCommerce AJAX endpoint `wc-ajax=add_to_cart`;
- endpoint создаёт стандартные cookie `wp_woocommerce_session_*`, `woocommerce_items_in_cart` и `woocommerce_cart_hash`;
- после добавления интерфейс получает актуальную корзину через Store API, поэтому сохраняются текущие состояния кнопки, количества и счётчика;
- для вариативных товаров endpoint получает ID выбранной вариации и её атрибуты в формате WooCommerce;
- резервный Store API путь оставлен для окружений, где Woo AJAX URL недоступен;
- версия темы повышена до `1.2.4`, чтобы браузер загрузил исправленный JavaScript без старого кеша.

## Автоматическая проверка

- JavaScript прошёл `node --check`;
- PHP темы прошёл `php -l` внутри Docker;
- браузерный тест в чистом профиле Chrome прошёл полный сценарий для простого электронного и вариативного физического товара: карточка → клик → счётчик `1` → `/cart/` → товар виден, пустого состояния нет;
- `test-cart-flow.php`: PASS;
- `test-mixed-delivery.php`: PASS;
- `test-checkout-progress.php`: PASS.

Повторяемый браузерный тест: `node scripts/test-product-cart-browser.mjs`.

## Минимальная ручная приёмка

1. Обновить карточку товара сочетанием `Ctrl+F5`.
2. Нажать «Добавить в корзину» один раз.
3. Убедиться, что счётчик корзины стал `1`, а кнопка перешла в состояние «В корзине».
4. Нажать «Корзина» в шапке.
5. Убедиться, что товар отображается и сообщения «Ваша корзина пока пуста» нет.
6. Обновить `/cart/` обычной клавишей `F5`: товар должен остаться.
