# Логическая итерация 7A — поиск и выдача результатов

Дата: 10 октября 2026 года.

Статус: **ПОИСК ГОТОВ К ОТЛОЖЕННОЙ РУЧНОЙ ПРОВЕРКЕ**. Остальные части широкой итерации 7 — каталог, отдельные UX-дефекты и device matrix — ещё не объявляются завершёнными.

## Исправлено

- Ранее `/search/?s=...` возвращал header/footer без списка результатов, потому что в теме отсутствовал `search.php`.
- Добавлен полноценный responsive search template с товарами, статьями, количеством результатов, повторным полем поиска и пагинацией.
- Старый action `/search/` конфликтовал с разбором WordPress как `category_name=search` и давал SQL-условие `0 = 1`; формы переведены на канонический `/?s=...`, а старый URL оставлен совместимым.
- Товары всегда ранжируются выше релевантных статей.
- Exact/full-title выше synonym, prefix и bounded typo match.
- Числовая версия обязательна: запрос `Office 2099` не подменяется Office 2021/2024.
- Поддержаны RU/EN-алиасы, разговорные формы, слитное написание, транслитерация, распространённые опечатки и неверная раскладка клавиатуры.
- В карточку товара добавлено ACF-independent поле «Синонимы поиска».
- Мобильный поиск больше не содержит жёстко записанное «164 товара» и использует актуальный published count.

## Примеры подтверждённых запросов

| Запрос | Первый релевантный результат |
|---|---|
| `Windows 11 Pro` | Windows 11 Pro (Профессиональная) |
| `Виндовс 11 Про` | Windows 11 Pro (Профессиональная) |
| `w11 pro` | Windows 11 Pro (Профессиональная) |
| `цштвщцы 11 зкщ` | Windows 11 Pro (Профессиональная) |
| `Офис 2021` | Microsoft Office 2021 Professional Plus |
| `offce 2021` | Office 2021 family |
| `Office 2099` | пустая выдача |

## Минимальная ручная проверка

1. В header найти `Windows 11 Pro` — первым должен быть одноимённый товар.
2. Повторить для `Винда 11`, `w11 pro`, `Офис 2021`, `offce 2021`.
3. Ввести `Office 2099` — увидеть понятную пустую выдачу без неверного товара.
4. Открыть любой товар в admin, заполнить «Синонимы поиска», сохранить и найти по новому синониму.
5. Проверить результаты на desktop и телефоне: карточки не выходят за экран.

## Дополнение 7B–7D — каталог, mobile, статьи и account

Статус: **ЛОКАЛЬНО ГОТОВО К РУЧНОЙ ПРИЁМКЕ**.

Исправлено:

- SEO-описание категории перенесено под сетку товаров.
- Для дочерней категории добавлена явная ссылка `← Назад в …`.
- Mobile burger открывает каталог с первого нажатия; close возвращает прокрутку страницы и корректные ARIA-состояния.
- Устранён невалидный `button` внутри ссылки категории: переход и раскрытие подкатегорий теперь независимы.
- На 320/360/393/768/1024 px нет горизонтального scroll в каталоге.
- Статьи больше не расширяют mobile viewport: изображения/iframe/video адаптивны, grid допускает сжатие, метаданные переносятся.
- Удалены фиктивные показатели статьи `1 245` и `10`; автор и число комментариев берутся из WordPress.
- Cookie banner и обе кнопки помещаются на 393 px, согласие сохраняется в cookie.
- Login/register/lost-password доступны на 320/393/768 px; create/auth/reset/logout проверены отдельным smoke-тестом.
- Мобильные ссылки «Отзывы / Статьи / Скачать программы / Ответы на вопросы» ведут на реальные страницы.

Автоматические проверки:

- `wp eval-file /workspace/scripts/test-account-flow.php` — account lifecycle: PASS, временный customer удалён.
- PHP lint изменённых theme templates: PASS.
